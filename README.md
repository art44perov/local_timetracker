# WorkTracker — Инструкция по установке и запуску

## Структура файлов

Положите оба файла в одну папку:

```
worktracker/
├── tracker.py        ← Python-сервер
└── tracker_ui.html   ← Веб-интерфейс
```

-----

## Установка зависимостей

### Минимум (для любой ОС):

```bash
pip install flask
```

### Windows (для автоматического трекинга активных окон):

```bash
pip install flask pywin32 psutil
```

### Linux / macOS:

Трекинг активного окна работает только на Windows через pywin32.
На Linux/macOS программа запустится, но автоматического отслеживания
не будет — можно вести заметки и добавлять записи вручную.

-----

## Запуск

```bash
python tracker.py
```

Браузер откроется автоматически на адресе: **<http://127.0.0.1:5000>**

-----

## Функционал

### Дашборд

- Текущая активная программа и её заголовок
- Быстрая заметка (Ctrl+Enter)
- Сводка за сегодня: общее время, по клиентам, по категориям
- График по категориям (браузер / RDP / проводник / приложения)

### Заметки

- Каждая заметка фиксируется с точным временем
- Привязка к клиенту
- Фильтрация по дате
- Удаление заметок

### История

- Полная история всех сессий
- Фильтры: дата, категория, клиент
- Показывает длительность каждой сессии

### Отчёты & Графики

- Выбор периода: сегодня / неделя / месяц / произвольный
- Кольцевые диаграммы: по клиентам, по категориям
- Столбчатый график: динамика по дням (с группировкой по клиентам)
- Топ-20 приложений
- Все заметки за период
- Итоговая таблица по клиентам (время, сессии, %)

### Клиенты

- Добавление клиентов с цветом
- Редактирование, удаление
- RDP-хосты создаются автоматически при обнаружении

## Категории трекинга

|Категория   |Что попадает                                          |
|------------|------------------------------------------------------|
|🌐 Браузер   |chrome, firefox, edge, opera, brave, vivaldi          |
|🖥 RDP       |mstsc, удалённый рабочий стол (имя хоста из заголовка)|
|📁 Проводник |explorer, total commander, far manager                |
|⚙ Приложения|всё остальное                                         |

-----

## RDP-хосты

При обнаружении RDP-сессии программа автоматически:

- Извлекает имя хоста из заголовка окна
- Создаёт нового клиента (если такого нет)
- Группирует все сессии с этим хостом под одним клиентом

-----

## База данных

Данные хранятся в файле `worktracker.db` (SQLite) рядом с `tracker.py`.
Файл создаётся автоматически при первом запуске.
